# مدرب الأولمبياد · رياضيات وعلوم

منصة تدريب على أولمبياد الرياضيات والعلوم لطلاب المرحلة المتوسطة، وفق محاور حقائب المرحلة الأولى («رياضيات 1» و«رياضيات 2» و«العلوم») لأولمبياد العلوم والرياضيات الوطني «نسمو».

- `index.html`: المنصة للطلاب، مفتوحة دون رقم سري. لا تحتوي الإجابات ولا الحلول: التحقق من الإجابة وجلب الحل يتمّان في قاعدة البيانات (الدالتان `oc_check` و`oc_solution`)، والمفاتيح في جدول `oc_keys` لا يقرؤه أحد مباشرة.
- `review.html`: نسخة المراجعة (مفتاح الإجابات ودليل المراجعة)، مشفّرة بالرقم السري، وتُفتح من الرابط نفسه مع إضافة `review.html` في آخره.

## بناء نسخة الطلاب

```bash
node tools/build-student.mjs source.html index.html answers.sql keys.json
```
ثم تشغيل `answers.sql` في SQL Editor. لا تُرفع `answers.sql` ولا `keys.json` إلى المستودع.

## تعديل نسخة المراجعة

```bash
OC_PIN=الرقم node tools/crypt.mjs decrypt review.html source.html
OC_PIN=الرقم node tools/crypt.mjs encrypt source.html review.html
```

## الحسابات
- **ضيف:** يتدرب فوراً، ولا يُحفظ له شيء.
- **طالب:** يدخل بإيميله برمز يصله (دون كلمة مرور). يُحفظ تقدمه على أي جهاز، ويرسل تقريره إلى إيميله أو إلى معلمه.
- **معلم:** يُضاف إيميله إلى جدول teachers من لوحة Supabase، فينشئ مجموعات ويلصق إيميلات طلابها. يصل الطالبة طلب موافقة، ولا يرى المعلم تقدمها إلا بعد أن توافق، وتستطيع إيقاف المتابعة متى شاءت. يرى تقدم كل طالبة حسب الوحدة، وينزّله ملف CSV.
- تُخزَّن البيانات في Supabase بقواعد حماية على مستوى الصفوف: الطالب يرى تقدمه فقط، والمعلم يرى طلاب مجموعاته فقط. لا يُحفظ نص ما يكتبه الطالب على السبورة.
